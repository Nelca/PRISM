# 初回利用の理解と画面の軽量化（2026-09-20）

## 目的と参照

環境・サステナビリティ担当者が、初めての訪問でも「環境データを金額と判断材料へ変える」「投資判断・開示に同じ根拠を使える」「どの操作から始めるか」を理解できる状態を目指す。

構想書v2、設計判断D-01〜05、情報設計、UI/UX指示書第7版および2026-09レビューを参照。今回のユーザー依頼は全体の見た目・使いやすさの刷新を含むため、第7版の小規模コピー変更という範囲を拡張した。算定結果を推奨値と扱わず、利用者の判断と理由の記録を維持する。

## 変更

- 青い面積の大きなヘッダー・サイドバーを、白と淡いニュートラル色へ変更。主操作と現在地には青を使用（アスエネへの統合予定というユーザー指定に合わせて変更）。
- ホームは価値の説明、デモ閲覧／拠点登録、作業再開、全体工程、結果の順。導入の3段階にメリットを併記し、説明の重複を減らした。
- 次の操作は既存の `deriveOpenTasks` の先頭項目を表示。別の優先順位判定や新しい算定処理は追加していない。
- 説明の非表示保存・再表示、全工程の直接リンク、既存の対象別詳細への導線を維持。
- ナビゲーションのグループ名を業務の目的が伝わる動詞へ変更。
- 主要6画面の案内を操作と得られる結果の説明へ更新。ガイドの先頭にもデモ閲覧の入口を追加。
- 共通カード・表・ボタンの余白と文字階層を整理。モバイルでは結果の6指標を2列にし、長い作業名を折り返す。

## 検証

- TypeScript / ESLint: 通過。
- Vitest: 127ファイル・801テスト通過。
- 本番ビルド: 通過。初回はネットワーク制限によるGoogle Fonts取得失敗、接続を許可して再実行後に成功。
- ブラウザ: ホーム・価値算定のデスクトップ／390px表示、説明の非表示と再読み込み後の保持、モバイルナビの開閉と画面遷移を確認。
- ホームの390 / 768 / 1024pxでページ・main領域の横はみ出しなし、h1が1つであることを確認。主要10ルートのHTTP 200を確認。
- 既存の計算・API・DBスキーマは変更なし。実ユーザーによる初見理解の評価は未実施。

## 追加調整

ユーザーの指定により、アクセントと淡い背景を青系に統一。「次の操作」、使い方案内、結果要約の装飾的な左罫線を削除。カード境界・表の区切りなど、構造を示す線は維持する。
