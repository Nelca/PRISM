## 0. エグゼクティブサマリー

### 何を作るのか

企業が保有する環境データを、**財務判断に使える形式に変換するレイヤー**。計測は行わず、既存の計測データと公開データベースを入力として受け取り、次の3つの数字を出力する。

1. **未内部化コストと内部化率** — いくら払わずに自然を使っているか
2. **期待損失** — 自然への依存によっていくら失いうるか
3. **対策ROI** — いくら投じれば、いくら減らせるか(財務効果と環境アウトカムの2軸)

### なぜ今なのか

日本のSSBJ開示義務化が2027年3月期から始まり、自然関連はISSB S3(2027年最終基準予定)を経て2029〜2031年に義務化が見込まれる。規制が需要を強制的に作るため、市場教育コストを規制当局に肩代わりさせられる。

### なぜ他社にできないのか

自然の貨幣価値換算は、手法によって**同一項目で2桁(鉱物資源では5桁)の差**が出る。単一の正解が存在しない。この不確実性を隠して単一の数字を出す製品は信頼を得られず、不確実性を晒すだけの製品は使われない。**複数手法を中立に併記し、不確実性を構造化して監査に耐える形にする**という設計が、この矛盾を解く唯一の道であり、そこに参入障壁がある。

### 中核的な設計思想

M&Aのデューデリジェンス実務が、まさに同じ問題(単一の正解が存在しない対象を、判断可能な形式に整える)を数十年かけて解いてきた。その文法——調整ブリッジ、フットボールチャート、感応度分析、偶発債務の定量化、リスク対応の類型——を非財務情報に持ち込む。

## 1. 目的関数(Stage 0)

### 1.1 終端目標

> **生態系サービスの価値が交換可能になり、その保全・回復に経済的インセンティブが働く構造が成立している状態。**

炭素に限定しない。生物多様性、水、土壌を含む生態系サービス全般を対象とする。

### 1.2 最大化する量

```
アウトカム総量 = 反事実的確実性 × 到達規模
```

「介入がなければ起きなかった物理的環境アウトカム」で成立度を測定する。規模はこの式の一項であり、独立した要件ではない。

### 1.3 制約条件

| # | 制約 | 位置づけ |
|---|---|---|
| C1 | 自分が構築するプロダクトを経由すること | 固定制約 |
| C2 | 個人で構築可能であること | 固定制約 |
| C3 | 長期構造変化を優先(短期の規制ウィンドウは手段) | 優先順位 |
| C4 | 事業性は持続手段(目的ではない) | 非営利・標準化団体モデルも候補空間に含む |

### 1.4 評価軸

- **追加性**:介入がなければ起きなかった変化を生むか。情報提供のみでは弱い
- **レバレッジポイント**(Meadows):自律実行 > 意思決定点への統合 > 標準化 > 集約・アクセス
- **5問フレームワーク**:反事実、乗数、防御力、持続性、不可逆性
- **評価時点**:10年後の期待アウトカムで統一(恣意的な採点操作を防ぐため)

## 2. 理想状態と介入点(Stage 1)

### 2.1 2035年の理想状態(構造命題)

| # | 命題 |
|---|---|
| P1 | 計測が意思決定コストを下回っている |
| P2 | 自然に関する主張が第三者的に成立し、反証可能である |
| P3 | 受益者から供給者への対価の流れが恒常化している |
| P4 | 土地転用・調達・融資の決定場面に、生態系価値の経済的帰結が提示されている |
| P5 | 上記が特定主体の存続に依存せず、規制・会計基準・契約慣行に埋め込まれている |

### 2.2 価値交換の因果連鎖と欠落箇所

```
計測 → 単位化 → 検証 → 価格形成・交換 → 意思決定注入 → 実行
```

| 領域 | 欠落箇所 |
|---|---|
| **炭素** | 単位(tCO2e)は普遍、価格機構(ETS)も存在。欠けているのは検証の信頼性と意思決定注入 |
| **炭素以外** | 最上流から欠落。計測は高コスト、単位は不在(生物多様性は空間固有で代替不可能)、したがって検証・価格・交換が建たない |

**重要な観察:** AIによるデータ取得・構造化の障壁消滅が最も強く効くのは、炭素以外の領域における最上流(計測・単位化)である。炭素では計測が先に解けていたためAIの寄与は検証層に現れたが、自然では連鎖の根元に現れる。

### 2.3 構造的緊張とその解消

**空間固有性 vs グローバル規模。** 生物多様性は炭素と違い代替可能な単一コモディティにならない。これはC3(規模)と衝突するように見えるが、**資産はローカル、測定方法論と信頼構造はグローバル**という分離で解消する(不動産と同型——物件は動かないが、鑑定基準・格付け・REIT構造は世界共通)。

規模を「単一市場の大きさ」でなく「方法論が適用される決定の総量」で取る。

## 3. 候補評価と選定(Stage 2〜3)

### 3.1 独立に導出した候補と、既存案との照合

介入点から独立に候補を生成し、その後で過去の検討結果と突き合わせた(アンカリング排除のため)。

| 候補 | 内容 | 過去案との対応 | 判定 |
|---|---|---|---|
| α | 計測・単位化エンジン | 対応物なし | **分割・脱落**。計測は競合過多、単位化はガバナンス問題でC2違反 |
| β | 独立検証層 | **CTIが再出現** | 保留。単位分裂により検証対象が定まらない |
| γ | 受益者→供給者の支払オーケストレーション | — | **脱落**。BNG実証で需要の薄さが判明 |
| δ | 意思決定注入 | **炭素台帳が再出現** | 自然では価格前提を欠く。εに吸収 |
| **ε** | **自然開示の意思決定変換層** | **CTI+炭素台帳の統合形** | **選定** |

**再導出テストの結論:** CTIが独立に再出現したことは、その構造が経路依存ではなく必然だった証拠。ただし過去の全検討は炭素を暗黙の前提としており、スコープを生態系サービス全般に広げると、CTI(検証)と炭素台帳(意思決定注入)は**1つのポジションに統合される**。

### 3.2 対称評価

| 評価軸 | ε | ζ(炭素台帳) | β(検証単独) | γ(PES) |
|---|---|---|---|---|
| 反事実 | 強 | 中 | 中 | 弱 |
| 乗数 | 強 | 中 | 中 | 弱 |
| 防御力 | 強 | 弱〜中 | 中 | 弱 |
| 持続性 | 強 | 中 | 中 | 弱 |
| 不可逆性 | 強 | 中〜強 | 弱 | 中 |
| **主要死因** | 規制実行の遅延 | ERP吸収 | 単位分裂待ち | 非代替性による需要制約 |

## 4. 実証検証の結果

### 4.1 市場の実態(調査で確定した事実)

| 事実 | 含意 |
|---|---|
| TNFD採択企業は2025年11月時点で733社・56か国。日本が単一国最大で約130社 | 需要の初期母集団が存在 |
| ISSB S3はTNFDベース。Exposure Draft 2026年10月、最終基準2027年目標 | 自然の義務化は2029〜2031年見込み |
| SSBJは2027年3月期からプライム大企業に義務化、段階的にプライム全体(約1,600社)へ | 需要は確定的に拡大 |
| 英国BNGは義務市場だが、2025年6月時点でオフサイト単位の取引は登録地の2%未満 | クレジット取引型ビジネスは需要が薄い |

| Nature TechへのVC投資は2024年に$2.1B、600社超がマッピング済み | 計測層は競合激化 |

### 4.2 財務影響ロジックの実証的裏付け

| 発見 | 出所の性質 |
|---|---|
| 米国社債市場で生物多様性リスクプレミアムが出現し、COP15以降に強まっている | 査読研究 |
| **グリーンウォッシュ企業(talkのみ)は資金調達コストで罰せられ、整合企業(talk+walk)は報われる** | 査読研究(S&P1500) |
| 負の生物多様性開示文が1つ増えるごとに監査報酬が約2.61%上昇 | 査読研究 |
| 開示品質の低い企業が開示を改善すると負債コストを約1%節約(規制ショックを用いた自然実験) | 査読研究 |

**含意:** 単なる開示では不十分で、**開示と実態の整合**が価格を分ける。これにより、製品の価値の中心が「開示コスト削減」から「グリーンウォッシュ・ペナルティの回避と資本コスト最適化」へ移り、同時に**実態改善(walk)を促すインセンティブがROIロジックの内部に組み込まれる**。

**留保:** これらは米国・中国・欧州・ベトナムのデータ。日本市場・SSBJ固有の効果は未実証。初期は保守的に見積もる。

### 4.3 貨幣化の実現可能性

**部品は公開されている。発明は不要。**

| 資産 | 内容 | 規模 |
|---|---|---|
| ESVD | 生態系サービスの貨幣価値DB。166列のメタデータ、Int$/ha/年・2020年価格に標準化 | 8,500件超 |
| CE Delft 環境価格ハンドブック | 大気・水・土壌への汚染物質の貨幣価値。汚染物質/中間/エンドポイントの3階層 | 3,000物質超 |
| ENCORE | セクター別の自然依存・影響評価 | 167セクター |

### 4.4 なぜ既存製品が存在しないのか(最重要の発見)

**貨幣化手法の比較研究によると、同一の影響カテゴリに対する係数は手法間で概ね2桁の幅があり、鉱物資源では5桁に達する。** EU市民一人当たりの年間環境損害に適用すると、手法によって€224から€7,941まで35倍の開きが出る。

つまり、単一の数字を出す製品は**100倍外れうる数字を根拠なく選んでいる**ことになる。だから誰も製品化できていない。

**この事実が、製品設計の正当性を決定づける。** 手法間の乖離そのものを一級の出力として表示することが、唯一誠実な回答である。

### 4.5 監査基準との適合(ISSA 5000)

ISSA 5000は、サステナビリティ情報が本来的に測定・評価の不確実性を含むことを認めた上で、実務家が「企業がどのように適切な手法・仮定・データ源を識別しているか」を理解することを要求する。そして**不確実性が高まるほど、保証の焦点は結果の検証から、仮定・手法・開示の合理性の評価へ移る**。

**したがって「レンジは監査に通らない」という懸念は逆である。** レンジと前提を構造化して提示することが、この基準下では有利に働く。

| **ENCORE** | UNEP帰属。**改変・派生物は同一ライセンス条件での配布義務(share-alike)** | **要注意** |

## 5. バリュープロポジション

### 5.1 表と裏

| | 内容 |
|---|---|
| **表(顧客が買う理由)** | 3つの数字:未内部化コスト・内部化率 / 期待損失 / 対策ROI |
| **裏(競合が勝てない理由)** | その数字を信頼できるものにしている機構:不確実性の構造化、適合度ティア、前提台帳、重複検出 |

3つの数字自体は模倣可能。模倣困難なのは裏側である。

### 5.2 対象ユーザー

| 主体 | 意思決定の瞬間 | フェーズ |
|---|---|---|
| **A. サステナビリティ/IR担当者** | 開示作成、根拠の説明 | 初期(一次ユーザー) |
| **B. CFO/財務・経営企画** | 投資判断、資本コスト管理 | 初期(価値の主対象) |
| C. 投資家・銀行 | 与信・投資判断 | 中期(信頼表明グレードで) |
| D. 監査法人 | 保証業務 | 中期 |

### 5.3 なぜ模倣されないか

| 防御 | 内容 |
|---|---|
| **中立性** | 複数の計測ソースを横断して矛盾を検出するには、どのソースにも属さないことが必要。計測ベンダーは自社データを正とするため原理的に不可能 |
| **データ複利** | 変換辞書は扱う企業・地域・基準が増えるほど網羅性と精度が上がる。後発の参入コストが時間とともに上昇 |
| **上流ポジション** | ERP内で完結する機能ではないため、ERPに吸収されない。むしろAPIを供給する上流に立つ |
| **前提台帳の継承** | 期間比較の一貫性は監査要件。年度をまたぐ台帳の蓄積がスイッチングコストになる |

### 5.4 死因への対処

| 死因 | 対処 |
|---|---|
| **A. 市場教育コスト**(規制がないと動かない) | 規制が既にある一点(SSBJ気候→自然)に絞り、市場教育を規制当局に肩代わりさせる |
| **B. ERP・大手プラットフォームによる吸収** | 中立性を構造に埋め込み、上流ポジションを取る |
| **C. 効率化ツールへの転落** | 開示生成を入口(低価格)に降格し、**初期から財務レンズを製品の顔にする** |
| **D. 規制実行の遅延** | **気候起点で立ち上げ、自然を後から載せる**。収益がS3のタイミングに依存しない |

## 6. ビジネスモデル

### 6.1 DDからの輸入

M&Aのデューデリジェンス実務が同型の問題を解いてきた。輸入するのは**成果物の文法**であり、業務モデル(一回性の取引評価)ではない。

| DDの道具 | εでの対応 |
|---|---|
| Quality of Earnings(調整ブリッジ) | 報告財務 → 自然調整後財務 |
| Debt-like items(債務類似項目) | 未内部化コストを「自然債務」として扱う |
| フットボールチャート | 手法別レンジの併記(3階層で使用) |
| 感応度分析・トルネード図 | どの前提がレンジを支配するか |
| 偶発債務の定量化 | 期待損失(確率 × 影響額) |
| リスク対応の類型 | 対策の4類型(回避/低減/移転/受容) |
| Red flag report | 重大度順の論点一覧 |

### 6.2 発行体課金の呪いを破る:VDDモデル

評価される側が払うと信頼が崩れる(Verra、EcoVadisの構造)。M&A実務はこれに**第三の解**を持つ。

売り手が費用を負担するベンダーDD(VDD)が買い手に信頼される理由は3つ:
1. 提供者が買い手に**信頼表明書(reliance letter)を発行し、専門家責任を負う**
2. 手法が職業的規範で標準化されている
3. 提供者にとって一件の顧客より全案件での評判の方が価値が大きい

**信頼表明書は、開示企業が費用を払いながら、成果物の名宛人を投資家・銀行にする仕組みである。** これにより、読み手側への展開は新製品開発ではなく、同じレポートの宛先を増やすだけになる。

### 6.3 提供形態と課金

**3階層のティア構成:**

| ティア | 内容 | フェーズ |
|---|---|---|
| スクリーニング | セルフサーブ、概算把握 | MVP |
| 開示グレード | レビュー付き、監査対応可能な前提台帳込み | MVP |
| 信頼表明グレード | 専門家責任を伴い、投資家・銀行を名宛人にできる | フェーズ3 |

**課金構造:年額ベース + 深掘り地点数の従量。**

課金単位(深掘り対象)、監査上の重要性判断単位、開示上の優先地点単位が、すべて同一オブジェクト(MaterialIssue)に一致する。価格の説明が構造から導かれる。

### 6.4 市場規模(ピッチ品質の推定)

| | 規模 |
|---|---|
| **SOM(初期)** | 100社 × ARPU 500万円 = 年5億円 |
| **SAM(日本・中期)** | プライム約1,600社 × 平均300万円 = 年約48億円 |
| **TAM(グローバル・長期)** | ISSB S3を参照する40超法域 + 読み手側。年数百億〜1千億円のオーダー |

支払意思のベンチマーク:TNFD/マテリアリティ分析のコンサル費用(大企業で年数百万〜数千万円)、ESGデータ・格付けベンダーへの支出(年数百万〜1千万円)。

### 6.5 需要拡大の4ベクトル

1. SSBJのプライム全体への段階拡大(→約1,600社)
2. バリューチェーン波及(→供給網の非上場企業群)
3. ISSB S3による40超法域への地理的波及
4. 読み手側(投資家・銀行・監査・保険)の買い手化

## 7. カテゴリ体系

### 7.1 分類軸はTNFD構造を採用する

ESRS E1〜E5を主軸にするのは**誤り**。理由:

1. マテリアリティ概念が違う(ESRSはダブル、SSBJ/ISSBはシングル=財務)
2. ISSB S3の骨格はTNFDであり、TNFDはIPBESの5ドライバーで構成
3. **ESRSは「依存」と「影響」を分離していない**

**財務マテリアリティの本体は「依存」側にある。** 水源が枯れれば操業が止まり、送粉が減れば原料が高騰する——これが企業自身の費用として財務に効く。影響側は社会的費用であり、移行・規制リスクとして間接的に効く。

内部表現はTNFD 3軸(依存/影響ドライバー/自然の状態)に置き、ESRS等は**出力ビュー**として辞書で組み替える。

### 7.2 貨幣化のティア分け

| 軸 | カテゴリ | 扱い | 根拠・制約 |
|---|---|---|---|
| 影響 | **気候変動(GHG)** | **ティアI** | GX-ETS価格・炭素の社会的費用・削減費用。**実市場価格が存在する唯一のカテゴリ** |
| 影響 | 汚染 | ティアI | CE Delft 3,000物質 + LIME3 |
| 影響 | 土地・淡水・海洋利用改変 | ティアII | ESVD便益移転。不確実性最大 |
| 影響 | 資源利用/再生 | 水=I / 生物資源=II / **鉱物=III** | 鉱物は手法間5桁の乖離 |
| 影響 | 侵略的外来種 | **III(物理単位のみ)** | 適用ロジック不在 |
| 依存 | 水供給 | ティアI | 代替費用、水価格、生産関数 |
| 依存 | 送粉 | ティアII | 生産関数(収量減)。研究蓄積が厚い |
| 依存 | 水流調節・洪水緩和、土壌、水質浄化 | ティアII | 回避損害費用、代替費用 |
| 依存 | 気候調節 | ティアI〜II | 重複検出層で影響軸と整合 |
| 状態 | 生態系範囲・状態・種 | **III(物理単位のみ)** | **TNFD自身が単一指標の不在と合意形成途上を認めている**ため、貨幣化しないことが基準準拠 |

### 7.3 気候の扱い(重要な設計判断)

- **(a) GHGインベントリの算定エンジンは作らない** — 既存データの取り込みに徹する
- **(b) 財務影響変換は自前で作る** — ここが価値の中心

炭素算定プレイヤーと衝突するのは「算定」層であって、財務変換層ではない。むしろ彼らのデータを受け取る上流に立つ。

**気候を含める判断が製品全体を成立させる:**
- 唯一、実際に観測可能な市場価格が存在する(利用者が検算できる錨)
- 唯一、新たな計測を求めずに初日から財務影響を提示できる
- 内部化が実際に進行中の唯一のカテゴリであり、他カテゴリの将来像を示す実例になる

## 8. 中核エンジンの設計

### 8.1 設計の一行要約

> 出力は「金額」ではなく、**金額 + それが何を意味するか + どこまで信頼できるか**を分離不能な一体として持つレコードである。

既存のEP&Lが監査に耐えなかったのは、最終的に金額だけが独り歩きし、前提が失われたため。前提を金額に構造的に結び付けたまま流通させる。

### 8.2 価値概念の分離(最重要規律)

| 価値概念 | 意味 | 用途 |
|---|---|---|
| **交換価値** | 市場でやり取りされる価格に相当 | 会計接続、**財務マテリアリティ(SSBJ)**、依存側 |
| **厚生価値** | 社会が被る損失(WTP基準) | 社会的コスト表示、**インパクトマテリアリティ(ESRS)**、影響側 |

**この2つは足せない。** 全金額に価値概念タグを付与し、異なる概念の合算をシステムが物理的に禁止する。これだけで既存EP&Lの最大の弱点を1つ潰す。

### 8.3 適合度スコア(5次元)

便益移転の誤差は研究地点と対象地点の乖離から生じる。

| 次元 | 測定内容 |
|---|---|
| 生態的適合 | 生物群系の一致度 |
| 社会経済的適合 | 一人当たり所得・人口密度の差 |
| サービス定義適合 | 分類コード(CICES/TEEB)の階層一致度 |
| 時間的距離 | 研究年と評価年の隔たり |
| 空間スケール適合 | 研究地面積と対象面積の比、代替地の有無 |

```
適合度 = 加重幾何平均(5次元)
```

**幾何平均を使う理由:** 一つでも致命的な不一致があればスコア全体が沈む性質が、便益移転の実態に合致する。算術平均では、生物群系が全く異なる研究でも他が高ければ合格してしまう。

```
ティア判定: A = 一次評価相当の信頼
           B = 補正付き移転で実務使用可
           C = 桁の把握のみ(開示使用は非推奨と明示)
```

**Cを切り捨てず、Cとして明示して出すことが中立性の実装である。** 判断は利用者と監査人に委ねる。

### 8.4 補正

```
調整値 = 原値
       × 購買力平価換算(研究国 → 日本)
       × (対象地所得 / 研究地所得)^η       // η:所得弾力性(分布として保持)
       × 一般物価デフレータ
       × 生態系サービス相対価格上昇係数^(経過年数)
       × 面積スケーリング
```

**相対価格上昇係数の実装が、既存ツールに対する明確な技術的差別化になる。** 自然が希少化すると相対価格は一般財より上昇する。この補正を省くと過去研究値が系統的に過小評価になる。

### 8.5 不確実性の3層

| 層 | 内容 | 扱い |
|---|---|---|
| **i. パラメータ不確実性** | 同一条件の推計値の分布 | 分位点として算出、モンテカルロに投入 |
| **ii. 移転誤差** | 適合度から推定される移転行為由来の誤差 | ティアに対応する誤差分布として投入 |
| **iii. スコープ・方法論不確実性** | 何を含め何を除外したか、白地図該当、価値概念 | **数値に混ぜず、除外事項リストとして別枠で出力** |

層iiiを分布に溶かし込むと、除外の事実が見えなくなる。

### 8.6 ValuationRecord(全出力の原子単位)

```
ValuationRecord {
  影響カテゴリ / 物理量 / 対象地点
  価値概念タグ           ← 交換価値 or 厚生価値(合算制御に使用)
  手法ID(版番号付き)
  中心値 / 分位点レンジ    ← 層i + 層ii を伝播した結果
  適合度ティア(A/B/C) と 5次元スコア内訳
  適用した補正の一覧      ← PPP、所得弾力性、相対価格
  出典                  ← ESVD該当レコードID、原論文
  除外事項リスト          ← 層iii
  エンドポイント被覆メタデータ ← 重複検出に使用
  再計算ハッシュ          ← 同一入力の再現性保証
}
```

### 8.7 エンドポイント重複検出

貨幣化係数は互いに損害エンドポイントを重複してカバーする。

| パターン | 内容 |
|---|---|
| P1 | 炭素の社会的費用 × 生態系サービス損失(SCCには生態系被害が含まれる) |
| P2 | 汚染の環境価格 × 水質浄化サービス |
| P3 | 依存 × 影響(自社が依拠するサービスを自社が毀損している場合) |
| P4 | 炭素固定サービス × GHG排出(相殺の可否) |

**システムは自動控除しない。** 重複量の正確な特定自体が方法論的に困難であり、自動処理すると根拠不明の調整が数字に埋め込まれる。**検出し、選択肢を示し、選択を記録する。**

相殺(P4)は既定で禁止。有効化する場合は根拠・地理的時間的一致・恒久性の説明を必須とし、**総量と純量を必ず併記する**。

### 9.3 主要モジュールの要点

#### M2:スクリーニングと深掘りは同一パイプライン

```
評価実行(対象, 深度):
  深度=スクリーニング → セクター原単位 + ESVD要約値 → ティアC
  深度=深掘り        → 実測 + ESVD個別レコード照合 + 補正 → ティアA/B

優先度 = 感応度 + 財務エクスポージャ + 不確実性の大きさ + 開示必須性
```

**「不確実性の大きさ」を優先度に含めるのが要点。** 深掘りの価値は不確実性の縮小にあるため、投資対効果を事前に見積もれる。

**除外理由の記録を必須とする。** ISSA 5000は実務家に「重大な項目が見落とされていないこと」の検証を求める。網羅性の証拠が必要であり、含めたものだけでは足りない。この記録がM7のG6(選択的開示の検出)を可能にする唯一の情報源でもある。

**ESVD要約値の使用範囲:** 提供元自身が要約値の用途を「桁の把握とデータギャップ特定」に限定している。**スクリーニング(ティアC)でのみ要約値を使い、深掘りでは個別レコード照合に切り替える。** データ提供元の利用条件とティア構造が一致する。

#### M4:代表値はユーザーが選ぶ

```
システムが提供するのは判断材料であり、推奨ではない:
  - 各手法の適合度ティア分布
  - 各手法が採用する価値概念
  - 各手法が既にカバーするエンドポイント
  - 前年度に選択した手法        ← 事実の提示
  - 基準・ガイダンスが言及している手法か  ← 事実の提示

手法変更時: 変更理由の入力を必須化し、
           「前年度手法での再計算値」を並記
           (手法変更の差分と実態変化の差分を分離)
```

**手法間の乖離倍率の表示は必須要件。** 2桁ぶれる事実を隠して代表値だけ見せる設計は、製品の存在理由と矛盾する。

#### M5:QoEブリッジ方式

**ブリッジ1:自然調整後利益(交換価値のみ)**
```
報告営業利益(監査済み)
  − 既支払の環境関連費用の再分類
  − 依存リスクの正常化調整
  − 将来内部化見込みコスト
  = 自然調整後営業利益(管理会計上の分析値)
```

**ブリッジ2:社会的費用ビュー(厚生価値のみ)**
```
自然への総影響(厚生価値) − 内部化済み = 未内部化コスト
内部化率 = 内部化済み / 総影響
```

**2つのブリッジは物理的に別画面とし、合算を許さない。** 厚生価値を利益から引くと、企業の損益に社会的費用が混入し意味をなさない。

**自然債務(Debt-like items):**
```
自然債務 = Σ [ 未内部化コスト × 内部化確率(シナリオ, 時期) × 割引係数 ]
```
未内部化コストの全額を債務としない。厚生価値のすべてが将来内部化されるわけではない。

**表示:** ウォーターフォール図(QoE標準形式)、フットボールチャート、**非GAAP明示ラベルを全画面・全出力に構造的に付与**。

**期待損失と集中リスク:**
```
期待損失 = 発生確率 × 影響額
集中リスク: 同一水源・同一生態系に依存する拠点群を検出し、
           相関を考慮した同時発現シナリオで再計算
```
集中リスクは拠点を個別に見ていては発見できない。全拠点を登録している構造がここで分析的価値を生む。

#### M6:対策評価(追加性の本体)

```
対応手段の4類型(M&Aのリスク配分に対応):
  回避(Avoid)     … 調達先変更、拠点移転
  低減(Mitigate)  … 保全投資、効率改善
  移転(Transfer)  … 保険、契約条項でのリスク配分
  受容(Accept)    … 引当計上、監視継続

自然調整後NPV = 通常NPV + Σ 回避される自然関連コスト(割引後)

比較表示(2軸):
  横軸: 単位投資あたり財務効果
  縦軸: 単位投資あたり環境アウトカム(物理量)
```

**2軸表示が製品思想の帰着点。** 財務効果のみで並べるとアウトカムの大きい対策が排除される。両軸の併置により、**終端目標(環境アウトカム)と手段(企業の財務合理性)が同一画面で接続される。**

#### M7:開示生成と整合検証

**位置づけ:公表前の自己点検であり、他社評価ツールではない。** 用語も「グリーンウォッシュ判定」ではなく「主張の根拠充足度」とする(断定的評価は法的リスクを伴い、後者は検証可能な事実の記述)。

```
段階1: AIで DisclosureClaim を抽出(抽出のみ。真偽判定はさせない)
段階2: 主張タイプの分類(状態/定量/傾向/比較/純量/将来約束)
段階3: 根拠の紐付けと充足度判定
段階4: ギャップ類型の判定

  G1 根拠不在      G2 根拠薄弱(ティアCのみ)
  G3 範囲不一致    G4 期間不一致
  G5 定義不一致    G6 選択的開示 ← εにしか検出できない
  G7 相殺依存      G8 約束の裏付け欠如
```

**AIの役割を抽出に限定するのは、素朴なLLM実装が実態評価を経ずグリーンウォッシュと区別できない回答を生成した事例への対策。** AIで抽出し、判定はルールで行う。

推奨アクションは3種:①主張を弱める ②根拠を追加取得する(深掘りへの導線=課金) ③意図的判断として記録する。**③を用意しないと実務で使われなくなる。**

#### M8:記録・版管理基盤

地味だが**堀の実体はここにある。** これがないとM4以降の全出力が監査に耐えず、ライセンス違反リスクも残る。

- AssumptionEntry の蓄積(判断が発生する全箇所で自動生成)
- 再計算ハッシュ(再現性)
- 係数セットの版管理と旧版での再計算
- ライセンス区分の制御(埋込可/参照のみ/要利用者ライセンス)

### 9.4 除外事項(製品価値の一部として明示)

| # | 除外 | 理由 |
|---|---|---|
| X1 | 自然の状態(種・生態系状態)を貨幣化しない | TNFD自身が単一指標の不在を認めている |
| X2 | 鉱物資源の枯渇を貨幣化しない | 手法間5桁の乖離 |
| X3 | 侵略的外来種は物理単位のみ | 適用ロジック不在 |
| X4 | GHGインベントリ算定エンジンは作らない | 既存プレイヤーの領域 |
| X5 | 独自の統合スコアは作らない | 標準戦争に巻き込まれない |
| X6 | 他社評価は行わない | 法的リスク、スコープ外 |

**「貨幣化しない」判断を製品仕様として明示することが、逆に信頼の証明になる。** 無理に貨幣化することこそが、εが解こうとしているグリーンウォッシュそのものである。

### 9.5 機能の循環

```
M2(網羅的な重要性判断の記録) → M7(選択的開示の検出) →
M2(追加深掘り) → M3(再評価) → M5/M6(財務判断) → M7(再検証)
```

**使うほど根拠が積み上がり、主張が実態に近づく。** 「入口は情報層、終端は実行層」が機能の循環として実装される。

## 10. ロードマップ

### 10.1 基本方針

| 方針 | 内容 |
|---|---|
| **気候起点** | 自然の義務化は2029〜2031年見込み。気候(SSBJで既に義務、GX-ETS価格が存在、データが社内にある)で立ち上げ、自然を後から同じエンジンに載せる |
| **縦串MVP** | 全モジュールを薄く、ただし全部入りで実装。コンセプト全体が刺さるかを検証する |
| **データモデルは最初から完全に** | 後から入れると全レコードの作り直しになるものは薄くしない |
| **並行実行** | 逐次ゲートをやめる |

### 10.2 薄くできるもの / できないもの

| 薄くできる | 薄くできない |
|---|---|
| 対応カテゴリ数(3つで十分) | ValuationRecordの構造 |
| 手法数(1カテゴリ2手法) | 不確実性のレンジ表示 |
| モンテカルロの反復数 | 適合度ティアのラベル |
| UI・グラフの作り込み | 非GAAP明示 |
| 対策案の類型(2つで十分) | ライセンス区分の制御 |
| 前提台帳のUI | 前提台帳のデータ構造 |

**薄いことと雑であることは別物。** レンジとティアの表示は実装コストがほぼゼロなのに、外すと製品の存在理由が消える。**安く早く出した数字が間違っていた場合、その損失は回復不能。**

### 10.3 AI活用による速度の見積もり

| 作業 | 圧縮率 |
|---|---|
| UI、CRUD、API、パイプライン骨格 | 5〜10倍 |
| 統計処理・モンテカルロ実装 | 5倍程度 |
| **データ取得・整形** | **1.5〜2倍**(ESVDの166列、産業分類マッピング、PDF抽出) |
| **設計判断** | **ほぼ1倍**(どの係数、どの重複、どのティア閾値) |
| **ライセンス確認・交渉、顧客接触** | 1倍 |

**全体では2.5〜3倍程度の圧縮が現実的。律速はコードから外部依存へ移る。** したがって計画の線は「実装期間」ではなく「外部依存の解消順序」で引く。

## 11. 未解決事項とリスク

### 11.1 未検証の前提

| # | 内容 | 影響 | 解消時期 |
|---|---|---|---|
| A-1 | CE Delft・LIME3のライセンス条項 | 主要係数が使えない場合、利用者ライセンス持込方式へ設計変更 | フェーズ0 |
| A-2 | ENCORE(share-alike)・WDPA(商用要許諾)の実務的影響 | プラグイン構造で緩和済みだが、許諾交渉が必要な可能性 | フェーズ0 |

### 11.2 主要リスク

| リスク | 内容 | 対処 |
|---|---|---|
| **規制実行の遅延** | ISSB S3・SSBJのスケジュール後退 | 気候起点により収益がS3に依存しない構造 |
| **外部依存による遅延** | ライセンス・データ入手が想定より重い | フェーズ0の並行実行で早期に可視化。**AIで圧縮できるのはコード部分のみ** |
| **効率化ツールへの転落** | M5だけが使われM6/M7が使われない | フェーズ1末の判断基準で早期判定 |
| **単一標準への収斂** | S3が単一手法を確定させ変換需要が消滅 | TCFD→ISSBの前例では単一標準確定後も併存が続いている |
| **信頼の毀損** | 早く出した数字が間違っていた | レンジ・ティア・前提台帳を薄くしない原則 |

### 11.3 追加性に関する自己点検

εは入口(開示・情報提供)ではレバレッジが低い。追加性は**M6(対策評価と意思決定注入)が実際に使われること**によってのみ回収される。

したがって、収益が出ていても以下は独立に評価する:

> **M6が使われなければ、εは情報提供層に留まったことになり、終端目標(生態系サービスへのインセンティブ構造の修復)に届いていない。**

| 段階 | 内容 | 主な結論 |
