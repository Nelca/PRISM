# GVFD V2の取得・算定実装（2026-09-24）

## 完了した範囲

IFVI公式ZIPに含まれる `IFVI_Environmental Methodology_Global Value Factor Database V2.xlsm` を取得し、研究用途の算定機能へ組み込んだ。以前の「GVFD未取得」は解消した。空のフォーム以外に公式資料一覧から直接取得できる導線があった。

- 一覧：https://ifvi.org/methodology/environmental-topic-methodology/interim-methodologies/download-the-interim-methodologies/
- 原本：https://ifvi.org/wp-content/uploads/2024/10/IFVI_Environmental-Methodology_Global-Value-Factor-Database.xlsm.zip
- 原本のVersion control!C10:E10：v2、2025-04-03。廃棄物の不快影響を更新し、単位の誤記をkgからmetric tonneへ訂正。
- 元のZIPとxlsmを `docs/data/research/raw/` に保持。ダウンロードURL上の2024/10を版の日付として扱わない。
- 通貨・価格年：USD2023。分野ごとの原本上の方法論ステータスと更新日も保持。

## 利用方法

`/research/gvfd` または統合管理の「GVFDで環境影響を算定する」を開く。研究機能の既存設定 `PRISM_RESEARCH_ENABLED=1` が必要。

1. 評価対象と国・地域を選び、係数を表示。
2. 物質／用途／廃棄物の種類、排出源条件／排出先／処理方法を選択。
3. 対象年と現状数量、任意で比較数量を入力し、適用条件を確認して算定。
4. 使用した影響成分と係数、原本セル、現状・比較の差を確認。出典付きの計算記録をテキスト保存・コピーできる。

統合管理のGHG・水消費・直接排出・廃棄物・土地改変の指標詳細には引継ぎリンクを追加。現在のテナントの実測値・目標値・単位・対象年を渡す。物質・地域・処理方法は自動推定しない。元レコードのID・版・範囲・根拠を結果のエクスポートに残す。アーカイブ済み、別テナント、対応しない指標のURLは404。比較数量の変更は管理レコードへ書き戻さない。

## 算定と誤適用の防止

- 原本の単位へ数量を換算し、各成分は数量×係数、合計は選択した条件に対応する成分の和。
- 大気汚染は都市・近郊・農村・輸送を重複加算せず、同じ物質のN/A条件の共通成分を一度追加。
- 未収録の成分が一つでもある場合は全体の算定を停止。別の国や平均値で黙って補完しない。
- 型の違う単位・価格年・対象、重複成分を拒否。負数、NaN、無限大、計算上限超過を拒否。
- 入力変更で古い結果を消去。単位変更時は数量を空にし、1000倍の誤読を防ぐ。
- 比較0はゼロとして計算、空欄は比較なし。現状との差が負なら「増加」と表示。
- 社会への影響額をUSD2023で表示。円・会社の現金支出・自然債務・M6投資判定には自動変換・加算しない。
- 単一の活動条件に対する収録成分の和であり、すべての環境影響を網羅するとは主張しない。廃棄物と大気／GHG等の異なる試算間での重複計上に注意を表示。

## GVFDだけでは埋まらない範囲

生物資源の調達重量、一次鉱物資源の投入重量、送粉頻度、観察個体数に直接掛ける係数は原本にない。これらは既存の物理量・目標管理と合成データによる感度分析を継続する。土地面積や排出量への変換根拠がないまま、GVFD係数を流用しない。

研究結果はブラウザー上で算定し、テキストで保存する。DBへの算定履歴保存、本番手法レジストリの変更、異なる活動の自動総合評価は今回含めない。
