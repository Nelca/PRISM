# 公開資料・合成データによる実験実装（2026-09-21）

ユーザーの追加指示により、実顧客データ待ちから「公開事例を参考に合成データで検証」に切り替えた。商用ライセンスの取得を研究用の実装開始条件にしない。以前の送信指示待ちは、この研究実装のブロッカーではなくなった。

## 使い方

ローカルの `/research`（統合管理の「公開データ・合成データで検証する」）を開く。

- 送粉低下と対策費用：収量・単価・依存度・機能低下率・回避率・費用を変更して、売上減少仮説と対策単体NPVを試す。
- CE Delft：EU27平均条件の大気排出をkgで入力し、EUR2021の厚生損失を下限・中央・上限で計算。
- ESVD：原研究を選び、標準化値に仮定面積を掛ける。Int$2020/ha/年の単位と原研究の地域・方法を維持する。
- IFVI：公式方法論Table 5に掲載された視程低下の部分費用をtで試す。米国の元研究値（USD2011）であり、国別総影響ではない。
- 合成データ：保存先の検証拠点を選択し、4指標をプレビューして保存。通常の統合管理・担当期限・年度引継ぎ・文案レビューへ接続。

研究画面は `PRISM_RESEARCH_ENABLED=1` のときだけ表示。今回、git管理外のローカル `.env.local` に有効化設定を追加した。未設定なら404。外部係数を通常の手法レジストリに追加したり、既存の商用許諾設定を変更したりはしていない。

## 作成した合成データ

すべての数量・金額・目標・地点は架空。実在企業の値を複数社から混ぜた推定実績ではない。公開企業の業務・調査の設計を参考にし、値は独立した仮定として明示する。

| ケース | 仮定入力 | 検証すること |
|---|---|---|
| 架空リンゴ園A | 観察60回/20時間→72回/24時間、仮目標4回/観察者時間 | 観察努力量を考慮すると両年3回であり、件数だけで改善としない |
| 架空森林B | Parus minor、固定1km経路、両年同季節・2時間、10→12個体、仮目標15 | 同一種・同じ調査条件の目標管理。個体群全体の推定ではない |
| 架空木材C | 国内材の年間調達100t、比較110t、目標80t | 調達対策の費用試算・年度管理 |
| 架空アルミ工程D | 一次材年間投入200t、比較220t、目標160t | 資源投入と再生材対策の検討入口 |

「訪花昆虫の観察頻度」「対象種の観察個体数」を統合管理の指標に追加（計15指標）。個体数は整数のみを受け付ける。観察率は小数を受け付ける。調査設計の比較可能性は根拠欄で記録する。

送粉試算の初期仮定は、収量120t、単価250円/kg、依存度65%、機能低下20%、回避率50%、追加年間費用50万円、初期費用200万円、5年・5%。依存度等は感度分析用であり、作物の推奨値・研究から抽出した値ではない。減収仮説390万円/年、回避する減収195万円/年、追加年間費用控除後145万円/年。利益率・代替受粉・税は未考慮。売上と利益を同一視しないため、既存の財務ブリッジへ自動合算しない。

参考にした一次資料:

- [農研機構・花粉媒介昆虫調査マニュアル](https://www.naro.go.jp/publicity_report/publication/laboratory/niaes/139079.html)：果樹等の訪花昆虫を調査する設計。
- [サントリー・植生／鳥類調査](https://www.suntory.co.jp/eco/forest/protect/field-survey.html)：定点・経路・種名・個体数を記録する業務。
- [キリン・紅茶農園の環境調査](https://www.kirinholdings.com/jp/newsroom/release/2025/1110_03.html)：調達地の生態系調査の参考。茶の知見をリンゴの送粉依存度に流用していない。

## 取得した原本と組込範囲

取得ファイル・URL・取得日・SHA-256は `docs/data/research/manifest.json`。原本は同ディレクトリの `raw/`。再抽出は `lib/research/prepare_sources.py`（bundled Python + openpyxl/pypdf）。原本自体は編集していない。

### ESVD

[ESPによるDecember 2020版の配布](https://www.es-partnership.org/esvd/esvd-download/esvd-version-december-2020/)からExcelを取得。配布ページに非商用・研究・教育目的の利用案内がある。報告書の公開・帰属の条件は引き続き保持する。

4,808行、標準化値あり3,286行。ValueIDは4,798種類で重複が存在するため、原本の行番号と組み合わせて参照する。欠損を0にしない。原本のレビュー欄も保持する。全行の必要列を `esvd-2020.json` に正規化し、試算画面では日本または送粉に関する数値あり行を選択できる。複数研究・サービスを無条件に合算しない。2020版は旧版であり、2025版の67件等と同じ母集団として扱わない。

### CE Delft

[EU27版v1.1と正誤表](https://cedelft.eu/publications/environmental-prices-handbook-2024-eu27-version/)を取得。本文Table 3（印刷ページ32、PDFページ33）を目視し、正誤表の新値と一致するPM10・SO2・NH3・NMVOCの4物質を組込。

NOxの上限は本文Table 3が31.1、要約と正誤表が31.8。PM2.5の中央も本文と正誤表に差があるため、今回はどちらかを黙って採用せず対象外とした。CEの総費用へIFVIの視程費用を足すと重複する可能性があるため、別試算として扱う。

### IFVI

[Air Pollution Interim Methodology October 2024](https://ifvi.org/wp-content/uploads/2024/10/IFVI_Environmental-Methodology_Interim-Air-Pollution-Topic-Methodology.pdf)を取得。Table 5（PDF／印刷47ページ）を目視して6物質の視程低下成分を組込。USD2011/tの部分費用であり、国別健康影響等を含むGVFDの代わりではない。

GVFD本体の[公式取得ページ](https://ifvi.org/methodology/environmental-topic-methodology/interim-methodologies/download-form-global-value-factor-database/)は、実ブラウザーでも見出しだけで入力・ダウンロード部が表示されない。ホームと移管先の案内も同じ取得導線を参照する。公式モデル取得ページも同様。第三者の再加工データを公式原本と偽って使わず、本体の取得を未完了として残す。未完了の理由は商用許諾待ちではなく、公式取得導線が機能していないこと。

## 実装境界

研究用の結果は原単位・価格年と入力仮定を含めてテキスト保存できる。編集すると古い結果を消し、再計算を求める。外部係数の本番レジストリ、交換価値／厚生価値の区別、通常のM5/M6の判定は変更しない。

今後GVFD原本を取得したら、地域・圧力・単位・価格年・版を保つローダーを追加し、現在の部分試算とは別に国別総影響を検証する。

## 検証結果

- ユニットテスト：133ファイル・863件成功。
- 対象DBテスト：2ファイル・6件成功。研究用4指標のプレビュー・一括保存・復元を追加検証。
- lint・型チェック・本番ビルド成功。
- ブラウザー：4種類の試算、ESVDの面積0、入力変更時の旧結果消去を確認。
- 隔離テナント `portfolio-ui-test` で4指標を保存し、統合管理の実測・目標・判定・担当期限への反映を確認。通常テナントへのテストデータ自動登録はしていない。
- 通常のローカル環境 `http://127.0.0.1:3000/research` でも画面と出典付き結果を確認。
- 外部資料を使う試算のテキストにはURL・取得日・SHA-256を含める。

残るデータ取得はIFVI GVFD本体。現在の研究機能を試すためにユーザーが用意する必須資料はない。GVFD本体を入手できた場合は公式配布ファイルを保存し、そのパスを共有すれば国別係数の組込へ進める。送粉の因果係数や地域移転の妥当性を実証した状態ではなく、仮説による機能検証である。
