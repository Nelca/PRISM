# PRISM LP デザインレビューと改善記録

対象：`public/promotion/index.html` / `style.css`。ユーザー添付の３点を起点に、LP全体をレビュー。

## レビュー結果と実装

| 問題 | 閲覧への影響 | 改善 |
|---|---|---|
| 製品説明が12〜13px、補足が8〜11px | 何ができる製品かを読み取るために拡大が必要 | 本文16〜18px、導入文18〜20px、注記14px以上へ整理 |
| 暗い背景で細い灰色の文字を多用 | 重要な説明が装飾に埋もれる | ヒーロー本文を明るい `#E3E9F3`、補足を `#D2DBE9` に。明るい背景の本文・補足も色を統一 |
| 英語の章番号・ラベルが文脈を説明しない | 内容の理解より解読が先になる | 「具体例で見る、評価と判定」「PRISMでできること」等の日本語へ |
| ヒーロー下の横帯が後続説明と重複 | 小さな文字の工程だけが残り、情報の優先順位が曖昧 | 横帯を削除し、主メッセージから課題説明へ直接つなぐ |
| 写真上の英語ラベル・フローが重複 | 写真と文字が競合し、読む場所が増える | 写真上の装飾ラベルと重複説明を削除 |
| 機能説明の棒グラフに単位やデータの根拠がない | 比較に意味があるように見えて、説明になっていない | 評価範囲・前提・判断基準・記録する根拠の具体的なリストに変更 |
| 判定例の数値・注記・次の行動が小さい | 結果と解釈の関係を把握しにくい | 数値19px、説明16px、注記14px。次の確認事項を淡い青の面で強調 |
| ボタンが小さく選択状態が色に依存 | モバイルでの操作・認識が難しい | 操作領域を拡大。モバイルは縦並び、「選択中」の表示を追加。aria-pressedを保持 |
| 見出しが狭い画面で孤立した短い行を作る | 読むリズムが崩れる | 「評価の幅が、判断を変える。」等へ整理し、モバイルの改行・均等な折り返しを調整 |
| 追記したCSSの上書きが重複 | 意図しない小さい文字の復活や調整漏れを招く | スタイル全体を整理し、画面幅ごとの文字・余白のルールを集約 |

## 維持したもの

指定のメインコピー・サブコピー・製品説明、モノトーン＋青、財務影響の算定・評価・判定という訴求、節水設備を明示した架空例、判断の限界に関する説明を維持。プロダクト本体のUI・業務ロジックは変更しない。

## 検証

- Chrome：1920 / 1440 / 1024 / 820 / 800 / 768 / 390 / 320pxで横方向のはみ出しなし。
- 通常表示のHTMLテキストを計算済みCSSで検査。14px未満なし、文字と背景のコントラスト比は最低5.32:1。
- 1440px画面の200%拡大相当となる720 CSS pxの幅でもリフローを確認。
- PCとモバイルのヒーロー、判定例、機能説明を画像で目視確認。
- 指定コピーの一致、判定例３ケース、キーボード操作、FAQ、ダウンロード、動画の再生とシークの既存検証を通過。

コントラスト検査は通常表示のHTMLテキストが対象。動画内の文字、ブラウザ標準コントロール、すべての操作状態を含むWCAG全体の適合認証ではない。Safari・実機端末は未検証。

検証スクリプト：`tools/promotion/review-ui.cjs`。数値と画面幅別結果：`output/promotion/ui-review.json`。
