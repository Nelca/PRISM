# PRISM 映像・アートディレクション

## 納品仕様

| 素材 | 仕様 | 用途 |
|---|---|---|
| prism-brand-45s.mp4 | 1920×1080 / 16:9 / 45秒 / 24fps / H.264 / AAC | LP、商談導入、説明会 |
| prism-social-15s.mp4 | 1080×1920 / 9:16 / 15秒 / 24fps / H.264 / AAC | SNSの縦型投稿・短い紹介 |

すべての動画に主要コピーを焼き込み。ナレーションなし。無音のタイムラインでも内容が分かる構成。VTTは画面の情報を補完するアクセシビリティ用で、プレイヤー上で任意表示する。

## 45秒の編集構成（2026-09-27改訂）

| 時間 | コピー | 伝える内容 |
|---|---|---|
| 0〜6秒 | 節水設備への投資。その費用は、見合うか。 | 最初から具体的な設備投資の用途を示す |
| 6〜12秒 | 取水量と対策費用から、投資効果を試算。 | 入力するデータと出力が分かる |
| 12〜19秒 | 試算結果が、赤字にも黒字にも。 | NPVが−800万円〜＋1,800万円という架空例 |
| 19〜27秒 | 水利用量やコストの前提を確かめてから、投資を判断。 | 承認基準をまたぐ場合に、次に確認する条件 |
| 27〜34秒 | 試算を、稟議・開示の説明に使う。 | 金額への換算・投資基準との比較・根拠の記録 |
| 34〜40秒 | CO₂削減・節水を、費用と効果で比較。 | 製品の用途を再提示 |
| 40〜45秒 | 環境対策の費用対効果を、投資判断の根拠に。 | 節水設備の試算例を見るCTA |

グラフは説明用の固定値。製品の実際の算定結果、顧客事例ではない。企業側の財務影響に使える環境関連コストを考慮する概念であり、社会全体の影響額をそのまま会社の利益へ加減算するものではない。

## 15秒の編集構成

- 0〜5秒：「節水設備の投資効果を試算・比較。」取水量・対策費用を入力する用途。
- 5〜10秒：「試算は赤字か、黒字か。基準と比較。」NPVの図と、水利用量・コストの確認。
- 10〜15秒：「環境対策の費用対効果を、投資判断の根拠に。」LPの試算例へ案内。

主要コピーを焼き込み、無音でも内容が分かる。上下の余白を取り、入稿時に媒体のUIとの重なりを確認する。

## 音

本制作専用に、合成音による穏やかな短いスコアをプログラムで生成。第三者の既存楽曲や録音は使用していない。ピアノに近い倍音と静かな持続音を組み合わせ、ナレーションや台詞に依存しない。ブランド映像を静かに支える音量。45秒・15秒それぞれにフェードを設定。

音源の生成ロジックは `tools/promotion/render_media.py`。再編集時に市販楽曲へ置換する場合、その楽曲の配信・広告利用条件は別途確認する。

## 見た目のルール

現行製品の `app/globals.css` に合わせたモノトーン＋青。緑・生成り・金色のハイライトは使わない。

- 背景：`#F7F8FA`、白、ニュートラルなチャコール `#17191D`。
- 本文：製品のInk `#273345`。補足は `#59616D`。
- アクセント：製品の青 `#2864DC`。ボタン・グラフ・番号・強調語。
- アクセントの補助：`#2054BD`、淡い青 `#EEF4FF`。暗い背景の文字は可読性のため明るい青。
- 大見出しの明朝と本文の角ゴシック、余白を生かす基本レイアウトは維持。
- 写真はImageGenで配色を改訂。グリーンと琥珀色を、無彩色と青い屈折光へ変更。
- 改訂版の原画像は `prism-hero-blue.png`。配信用は `prism-hero.jpg`。

抽象的なブランド表現だけで説明を終えず、「登録するデータ → 試算 → 社内基準との比較 → 稟議・開示」の順で用途を示す。

## 再生成

PythonはPillow・numpy、動画はffmpegが必要。フォントはmacOSのヒラギノを利用。別OSでは日本語フォントを環境変数 `PRISM_JP_FONT` と `PRISM_SERIF_FONT` で指定し、英数字フォントの定義も調整する。

```sh
python3 tools/promotion/render_media.py --ffmpeg /path/to/ffmpeg
```

静止画だけの再生成は `--stills-only`。元素材を上書き編集せず、必要ならファイル名を分けてバリエーションを作る。
