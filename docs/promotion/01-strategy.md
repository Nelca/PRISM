# PRISM プロモーション戦略

制作基準日：2026-09-26 / コピー・配色改訂：2026-09-27 / デザインパートナー獲得フェーズ

## 何を売るか

**排出量・取水量と対策費用を登録し、環境対策の投資効果を試算して、社内の承認基準と比較するプロダクト。**

主コピーは「環境対策の費用対効果を、投資判断の根拠に。」。機能の説明は「排出量・取水量と対策費用から試算し、社内の承認基準と比較する」。判断を自動化する、正しい価格を一つに決める、規制対応を完了する、という約束はしない。

環境価値の算定そのものは専門性が高く、購買担当者に手法の優劣を理解してもらうだけでは商談になりにくい。「既に数字はあるが、どの前提で稟議に載せればよいか迷っている」という具体的な場面を入口にする。比較と分解は説明の根拠、承認基準との照合は購入理由、履歴は継続理由として配置した。

現在の実装と資料から、企業実務での効果・商用利用条件を確認する段階と判断した。今回のLPは一般販売の完成宣言ではなく、検証案件を持つ相手との対話を作る紹介ページである。社数、削減率、費用対効果、世界初、顧客コメントは作らない。

## 最初に会う相手

| 区分 | 最優先の仮説 | 見極める証拠 |
|---|---|---|
| 企業 | 国内の化学・素材、紙・パルプ、食品など、拠点の環境負荷と設備投資を扱う製造業 | 排出・取水等のデータがあり、具体的な対策案の比較を予定している |
| 実務推進者 | サステナビリティ推進、環境管理 | 財務・事業部への説明に困った実際の案件がある |
| 購買・決裁関与 | 経営企画、財務、設備投資を持つ事業部 | NPV等の承認条件と検討期限を説明できる |
| 初回案件 | 既存設備の更新、排出削減・節水対策など、比較可能な選択肢がある案件 | 投資額、通常収支、物理量、前提の所在を特定できる |
| 紹介経路 | 環境評価・LCA・開示支援に関わる専門家、既存の業務上の接点 | 実務推進者と決裁関与者を同席させられる |

これは検証前のセグメント仮説。業界全体に需要があると断定しない。炭素・水のどちらから入るかも、対象の手法と係数が実務上使えることを確認して選ぶ。水の比較で「差をすべて説明できる」とは言わない。

適合が弱いのは、基礎的なデータ収集だけを求める企業、承認基準のない一般的なESG情報収集、既に判断が固定され説明資料だけを後付けしたい案件。「判断は変わらないと確認する」価値はあり得るが、独立した支払意思はまだ仮説である。

## 市場の読み方

一次情報を2026-09-26に参照。以下は各社自身が説明する提供内容の要約であり、独立した性能比較ではない。

| 市場・プレイヤー | 確認した訴求 | PRISMへの含意 |
|---|---|---|
| TNFD | 自然への依存・影響を財務リスク・機会へ接続する評価には課題があると説明 | 問題設定の背景にはなるが、PRISMの有効性の証明ではない |
| Natcap | 事業・サプライチェーンの自然リスクと潜在的な財務影響を評価 | 「経営判断につなぐ」だけでは独自性を主張できない |
| GIST Impact | 自然・生物多様性、影響・リスク、価値の定量化に関するデータと分析を提供 | 算定や影響額の可視化だけを前面に出すと広い分析市場で比較される |
| ASUENE | 排出量の可視化・削減・報告とサステナビリティ開示等を支援 | 収集・開示の全面置換を約束せず、既存データを判断に使う場面を示す |
| Booost | サステナビリティ情報管理・開示と経営管理をつなぐ訴求 | 抽象的な統合価値ではなく、案件単位の照合体験を見せる |

公開情報では競合の全機能や内部実装は分からない。「競合にはできない」「唯一の差の分解」などの不在証明はしない。既存の社内資料にある古い競合断定も、そのまま広告へ転用していない。

参照先：
- [TNFD Recommendations](https://tnfd.global/publication/recommendations-of-the-taskforce-on-nature-related-financial-disclosures/) — 依存・影響から財務リスク・機会への接続。
- [Natcap Nature Risk & Opportunity Assessment](https://natcapresearch.com/solutions/nature-risk-opportunity-assessment) — リスク・財務影響評価。
- [GIST Impact](https://www.gistimpact.com/) — データ・分析の提供範囲。
- [ASUENE](https://asuene.com/) — 可視化・削減・報告等の入口。
- [Booost サステナビリティと経営管理のセミナー紹介](https://booost-tech.com/seminar) — 同社のメッセージの競合性。

法令の施行時期、対象社数、市場金額は今回の対外制作物に使わない。期限への不安より、目の前の意思決定に役立つ理由を主軸にする。

## 顧客が買うまでの流れ

1. **気づき**：「その前提で、決めてよいのか。」という稟議の問いに接する。15秒動画・短い投稿・紹介文を使用。
2. **理解**：LPの３ケースを切り替え、評価の幅によって次の検討が変わると理解する。
3. **社内共有**：１枚PDFで、環境担当と財務担当が同じ説明を持てるようにする。資料は入力フォームなしで取得可能。
4. **適合確認**：ひとつの案件、手元のデータ、承認条件を整理。専門用語から始めず「何を決めたいか」を聞く。
5. **検証合意**：対象手法、データ利用条件、成果物、費用、判断への使い方を個別に決める。
6. **継続判断**：「数値が出た」ではなく、前提選択・追加調査・社内説明・意思決定のいずれかが改善したかを利用者が判定する。

LPのCTAは、初期段階で虚偽の予約完了を作らない設計。現在は「案件整理シートを保存」。実在する相談窓口を `public/promotion/config.js` に設定すると「検証について相談する」へ切り替わる。

## オファーの設計

対外呼称は「ひとつの投資案件を題材にした検証相談」。無料、期間限定、先着社数は確定していないので書かない。初回相談で検証範囲と条件を整理し、開始前に合意する。

検証成果物の提案：入力・前提の棚卸し、比較可能性の確認、評価の幅と承認基準の照合、追加確認事項、採用理由の記録。再現できない分解は実施済み扱いにしない。入手できないデータが結果を左右するなら、その事実を成果に含める。

## 30日間の初期運用案

以下の件数は予測や市場平均ではなく、少人数で学習を回すための内部目安。広告の出稿・連絡は今回実施していない。

| 期間 | 実施 | 得たい証拠 |
|---|---|---|
| 1〜3日 | 相談窓口・運営主体を確定し、担当者3名程度に資料の理解度を確認 | 「何ができるか」を相手の言葉で再説明できるか |
| 4〜10日 | 許諾・関係性のある紹介経路から候補10社程度へ個別案内。対象案件を伴う企業を優先 | 課題、データ、承認条件のうち何が欠けているか |
| 11〜17日 | 30分の適合確認。環境担当と財務・事業部の同席を依頼 | 具体的な意思決定の名前・期限・責任者が出るか |
| 18〜24日 | 適合する2〜3案件に検証案を作成 | 実際に使えるデータ・手法と、評価される成果物 |
| 25〜30日 | 相手の反応でコピーと対象業種を見直す | 面談数より、検証条件の合意に近づいた理由 |

LP閲覧数よりも「案件を持つ適合面談」「財務または事業部の参加」「対象データが特定できた検証案」を重視。最初の少数面談から統計的な勝ちコピーを認定しない。

記録する分母：案内数 → LPへの訪問 → 体験操作 → 資料取得 → 適合相談 → 検証案 → 合意。今回は外部解析ツールを接続していない。導入時には同意・プライバシー方針と合わせて選ぶ。計測イベント案は `06-launch.md` を参照。

## クリエイティブの判断基準

- 明朝の見出しと青の図で、環境領域の専門性と財務議論の落ち着きを両立。
- 植林写真や握手写真ではなく、ひとつの光を分けるプリズムを独自の視覚モチーフにする。
- 大きな約束より、小さく具体的な判断体験を証拠として置く。
- コピーは「担当者の能力不足」を責めず、複数の前提がある構造を言葉にする。
- 動画は無音でも意味が通る。音楽は補助。生成音声のナレーションは採用していない。
- プロモーションの表現と、製品の機能上・実証上の限界が矛盾しないことを優先する。
