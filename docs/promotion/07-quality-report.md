# PRISM プロモーション 検証記録

制作日：2026-09-26 / 検証環境：macOS・Google Chrome（Playwright）、ffmpeg、Poppler、pypdf。

## 確認済み

- LPを1440・1024・768・390・320px幅で表示し、横方向のはみ出しなし。
- 1440pxと390pxの実ブラウザ画像を確認。見出し、画像、図、ボタンの重なりなし。
- 判断体験３ケースの両端数値と選択状態が正しく切り替わる。
- ボタンのキーボード操作、FAQの開閉、整理シートのダウンロードが動作。
- HTMLが参照するローカルアセットの存在、画像読み込みを確認。
- JavaScriptのページエラーなし。JavaScriptファイルの構文検査通過。
- 横型MP4をブラウザで再生し、22秒位置へのシークを確認。
- 横型MP4：45秒、1920×1080、24fps、H.264 / AAC。
- 縦型MP4：15秒、1080×1920、24fps、H.264 / AAC。
- 両MP4をffmpegで全編デコードし、エラーなし。
- 横型の音声信号にクリッピングなし。専用の合成音楽を収録。画面内コピーだけでも意味が通る構成。
- 映像７場面のコンタクトシートを目視確認。縦型と正方形の画像は背景濃度を調整し、コピーの視認性を改善。
- 営業PDFはA4・１ページ。日本語テキスト抽出を確認。Popplerで画像化し、本文とフッターが重ならないことを確認。
- LP・動画・PDFの架空値、試算と実績、実装と実証の区別を確認。

機械検証の詳細は `output/promotion/browser-check.json`。視覚確認用の画像は同フォルダ。

## ローカルプレビューの改善

単純なPython静的配信では動画の途中再生に必要なHTTP Range応答がなく、シークの検証が通らなかった。LPやMP4の不具合ではなく配信条件の問題と切り分け、Byte Rangeに対応したローカル専用の `tools/promotion/preview.cjs` を追加。最終検証では再生・シークとも通過した。
