# PRISM 初回営業・商談キット

共通導入：算出方法で、変わる金額。 正解のない環境の評価額を、投資の根拠に変える。 PRISMは環境財務評価プラットフォームです。

メール等は下書き。相手への送信は行っていない。

## 紹介依頼の本文

環境投資の評価結果を、社内の投資判断にどうつなぐかを検討しています。

PRISMは、環境情報と事業・財務データから財務影響を算定し、重要性を評価して、設定した判断基準に照らして判定する環境財務評価プラットフォームです。例えば節水設備の導入で、想定する水利用量やコストによって投資効果がどう変わるかを確認します。現在は、具体的な案件で実務上の価値を確かめる段階です。

もし、環境投資の稟議や評価結果の説明に関わる方で、お話を伺える方がいらっしゃればご紹介いただけないでしょうか。サステナビリティ担当に加え、経営企画・財務・設備投資のいずれかの視点も伺えるとありがたく存じます。

まずは添付の１枚資料をご覧いただければ幸いです。

運用：既存の関係性がある相手向け。冒頭の宛名と紹介をお願いする理由は実際の関係に即して追記。添付は `prism-overview.pdf`。

## 初回案内メール

件名：環境投資の評価結果を、稟議の判断につなぐ検討について

環境投資を検討するとき、評価手法や前提によって数字に幅が出ることがあります。その幅をどう扱い、何を根拠に社内で説明するか。

PRISMは、環境情報と事業・財務データから財務影響を算定し、重要性を評価して、設定した判断基準に照らして判定する環境財務評価プラットフォームです。計算方法や採用した前提を残し、事業・拠点の対応方針や投資の検討、稟議・開示の説明に使います。

現在、ひとつの投資案件を題材に、手法の選択・追加調査・社内説明に役立つかを確かめる検証を想定しています。

もし現在検討中の環境投資がありましたら、案件の内容や判断の進め方について、30分ほどお話を伺えればと考えております。データの提供や検証の開始は、対象範囲と条件をご相談したうえで決める想定です。

概要を１枚にまとめました。ご関心がありましたら、ご都合のよい進め方をお知らせください。

運用：名乗り・連絡理由・実在の署名を追加。無関係な相手への一斉配信に転用しない。公開LPのURLかPDFの一方を主にし、最初から複数の行動を要求しない。

## 返信がない場合の補足メール

件名：環境投資の検討について、１点補足です

先日お送りしたPRISMについて、１点だけ補足いたします。

評価額を細かくすること自体が目的ではなく、「どの前提を置くと結論が変わるか」を確かめ、次に調べることや説明することを整理したいと考えています。

現在の業務に近い課題がありましたら、具体的な案件を念頭にお話を伺えますと幸いです。今回の対象と異なる場合は、ご返信には及びません。

運用：最初の連絡に関連性がある場合に１回のみ。間隔は相手との関係と日程に合わせる。

## 30分の商談進行

| 時間 | 行うこと | 守ること |
|---|---|---|
| 0〜3分 | 「今日は機能説明より、いま何を決めようとしているかを伺いたい」と目的を確認 | 課題を誘導して作らない |
| 3〜12分 | 直近の投資案件、評価結果、会議で問われたことを聞く | 抽象的な「困りますか」で終わらせない |
| 12〜18分 | LPの３ケースを一緒に見る | 架空値であることを明言。相手の実績に見せない |
| 18〜24分 | 実案件の承認基準と照らし、役立つ箇所・足りない箇所を聞く | 必要データと利用可能な手法を決めつけない |
| 24〜30分 | 検証範囲、関与者、次回までに確認することを合意 | 即座に導入を迫らない。価値がなければ理由を残す |

## 聞くべき質問

1. 直近で、どんな環境投資を、誰が、いつまでに決めますか。
2. その投資を通す条件は何ですか。数値基準以外に、必ず満たす条件はありますか。
3. 評価結果のうち、会議で説明しづらかった点はどこですか。
4. 手法や前提を変えると、現在の結論は変わりそうですか。その根拠はありますか。
5. 追加調査を行うなら、誰が、どんなデータを取得できますか。
6. この検証が役立ったと判断するために、何が変わればよいですか。
7. 既存のツール・専門家との役割分担はどうしたいですか。
8. 検証費用と継続利用費用の判断者は誰ですか。

## よくある反応への返し方

**『既にコンサルや算定ツールを使っています』**
既にある評価結果を、どのように社内判断へ使っているかを伺いたいです。収集や評価をすべて置き換える前提ではありません。PRISMで扱える入力と、今の役割分担が合うかを確認します。

**『正しい評価方法を選んでくれるのですか』**
一つの正解を自動で決めるという役割ではありません。評価の目的・対象範囲・前提の違いを確認し、採用した理由を残すことを支援します。比較できないものは分けて扱います。

**『評価額を利益から引けばよいですか』**
社会全体への影響額と企業の財務影響は別です。そのまま利益から引くことはしません。財務に使える値かを確かめ、試算として扱います。

**『差を全部説明できますか』**
対象によって、分解できる差と説明しきれない差があります。足りない情報や比較できない理由も含めて示す設計です。対象案件でどこまでできるかを検証します。

**『結局、投資の結論は変わらないのでは』**
変わらない可能性もあります。前提選択や追加調査、説明の仕方に価値があるかも含めて確認します。価値がなければ、その結果をもって継続を見送れる検証にしたいと考えています。

**『費用はいくらですか』**
現段階では、対象案件とデータ・手法を確認して検証範囲を設計する想定です。範囲、成果物、費用、継続条件を合意してから始めます。未確定の社内価格案を確定料金として提示しません。

## 次回提案の骨子

１案件、１つの意思決定、対象手法と入力の一覧、比較できる範囲、成果物、検証の責任者、費用・期限、成功・中止条件。実データを受け取る前にデータ取扱いと利用条件を決める。

成功条件は「モデルが動いた」だけにしない。利用者が、採用手法・追加調査・説明・投資判断のどれをどう変えたかを記録する。PRISMに有利な回答を求める設問は避ける。
