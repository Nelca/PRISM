## 2. 取り込んだデータ

`docs/data/external/aist-idea-lime3-v4.0-lcia-coefficients.csv`(980行)として、`LCIA係数_LIME3`シート(基本フロー単位の特性化係数、個別製品の計算結果ではなく元になる係数そのもの)を抽出した。**個人情報・ライセンス担当者名を含む行(シート先頭の表紙・ライセンス表示行)は除外し、データ本体のみを抽出済み。**

列構成:
- `基本フローコード` / `基本フロー名` / `分類1/分類2` / `評価領域`(単位)
- 4つの被害評価エンドポイント(人間健康=DALY、社会資産=US$、生物多様性=EINES、一次生産=kg-DW) × 4つの地理的視点(利子率2%固定、消費国/生産国 × 世界平均/日本)
- 統合化(IF2、単一指標化、US$) × 同じ4つの地理的視点

`LCIA結果_LIME3`シート(IDEA製品コード×約1万件の計算済み結果)は今回取り込んでいない。PRISMは基本フロー(水消費等)の物理量に直接特性化係数を掛ける設計であり、製品別の計算結果は現状不要なため(将来、CE Delft同様に他カテゴリへ拡張する際は再検討)。

## 3. `lime3-water`プラグイン向けの値の選定(要確認の判断を含む)

### 3.1 使う行:水消費(取水)

`docs/data/aop-mapping-v1.md` §0 の既存判断により、**MVP水パイロットの物理量は「取水量」**。CSV内では以下の基本フローが対応する:

| 基本フローコード | 内容 | 統合化(消費国、日本)US$ |
|---|---|---|
| 001511000 | 資源, 表層水, 水圏, 取水 | 0.0135886259 |
| 001515000 | 資源, 地下水, 水圏, 取水 | 0.0351039504 |

(「非消費型使用水」は取水のうち系外に排出されない/返される分を相殺する負の値として別行にあり、「消費型使用水」行自体は本データセットでは値が入っていない。取水量をそのまま使うのがCSVの構造と整合する。)

### 3.2 選んだ値:表層水(surface water)、消費国=日本

**採用値: `0.0135886259`(US$/m³、利子率2%・消費国=日本の統合化スコア)**

**判断根拠・注意点(未確認のまま残る仮定):**

1. **消費国 vs 生産国:** LIME3のこのデータセットでは、水関連フロー(取水・非消費型使用水)について「生産国」視点の列は**すべて空欄**(値が入っていない)。したがって選択の余地なく「消費国」視点の値を使う。他のフロー種別(大気排出物質等)では生産国視点にも値がある。
2. **表層水 vs 地下水:** PRISM側は現状、拠点の取水が表流水・地下水のどちらかを区別するデータを持っていない(`lib/demo/company.ts`・`user-site-defaults.ts`に水源種別のフィールドが無い)。**表層水を既定値として採用した。** 地下水は係数が約2.6倍高い(0.0351 vs 0.0136)。日本の産業用水の主要な水源は河川水(表流水)であることが一般的なため、表層水を既定としたが、**これは確認された事実ではなく実装上の仮定**である。拠点ごとの水源種別データが得られ次第、`外部fromValueFactors["lime3-water"]`を拠点別に出し分けられるよう見直す余地がある(現状はグローバル1本の定数)。
3. **通貨:** `lime3-water.ts`のコメントが元々「$/DALY相当の価値係数」を想定しており、`packages/core/src/monetization/calibration.ts`が地理較正(PPPによる円換算等)を一律適用する設計と整合させるため、**USDのまま(較正前の値として)**渡す。IFVIの`vfes`等と同じ扱い。会社側の`DEEP_DIVE_CALIBRATION`(pppValue=94.46円/国際ドル、sourceRegion=targetRegion="JP")が乗算され、最終的に円建ての値になる。
4. **価格基準年:** ファイル内に明示的な基準年の記載を発見できなかった(`利用方法`シートに記載なし)。今後原本のマニュアルで確認が望ましい(未確認事項として残す)。

### 3.3 完了条件との対応

`docs/data/acquisition-runbook.md` §3.5の完了条件(「使える/使えない/条件付き」の書面確定)に対して:**「使える」(既存ライセンスの範囲内)。** ただし上記3点(消費国/生産国の選択肢なし、表層水/地下水の仮定、価格基準年未確認)は今後の精緻化余地として記録した。
