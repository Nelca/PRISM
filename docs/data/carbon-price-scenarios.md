**目的:** M5 D-4.2が「未確認事項(実装前に一次資料で再確認すること)」として残した2点 —— NGFSの価格軌道と、GX-ETSの価格 —— の取得状況を記録する。GAP-11(`docs/requirements/mvp-completion-gap.md`)の前提データ。

**取得日:** 2026-08-08

| NGFS Net Zero 2050(Orderly) | 2030/2040/2050の炭素価格軌道(モデル・実質基準年つき) | **未取得。**§1 |

## 1. NGFS(未取得)

**必要な数値:** Net Zero 2050 / Current Policies の炭素価格軌道(2030・2040・2050)、採用モデル(REMIND-MAgPIE / GCAM / MESSAGEix)、実質基準年、可能なら日本またはOECD地域の値。

**試みた取得方法と結果:**

| 方法 | 結果 |
|---|---|
| NGFS Climate Scenarios Technical Documentation V5.0 のPDF直接取得 | **HTTP 403** |
| NGFS Phase V high-level overview PDF | **HTTP 403** |
| NGFS Scenarios Portal | シナリオデータ本体はIIASA Scenario Explorer上にあり、**アカウント登録とログインが必要** |

**二次資料で見えている水準(参考。実装に使わないこと):** Phase Vでは、2050年ネットゼロの秩序ある移行には2035年時点で約300 USD/tCO2のシャドウ炭素価格が必要という記述がある(Phase IVから+50 USD)。低需要シナリオでは2035年に約200 USD/tCO2。**これは年次・地域・モデルが特定されていない見出し数値であり、M5の算出に投入できる形ではない。**

**→ 取得手順は `acquisition-runbook.md` §3.2。**

## 3. 実装に落とすときの形(取得後の作業)

取得が完了したら、以下の形で登録する。**数値をコードに直接書かない。**

```
VersionedParameterSet {
  setId: "carbon-price-scenarios"
  version: "v1"
  effectiveFrom: <確認日>
  changeReason: <初版のため不要。更新時は必須>
}
```

シナリオ別の価格軌道(年 × シナリオ × 価格 × 通貨 × 実質基準年)を別データとして保持し、`computeNatureDebt()` がシナリオ別の未内部化コストを算出できるように拡張する(GAP-11)。**通貨と実質基準年を値と一体で保持すること**(NGFSはUSD実質、GX-ETSは円名目であり、混ぜると意味をなさない)。
