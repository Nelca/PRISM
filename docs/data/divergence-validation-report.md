**対象カテゴリ:** 水(取水・消費水)。厚生価値(LIME3・IFVI VFes/VFnutrition等)と交換価値(代替費用法・IFVI VFaccess)の混在。

**対象拠点:** site-042(デモ既定値)、取水量45,000 m³/年(デモ既定値・実測値ではない)

## 現行日本水ケースの負例

指示書 §3.3 「現在のIFVI日本水ケースを負例として残す」

### 負例としての学習価値

**IFVI日本水:** VFnutrition/VFdisease/VFaccess = 公表0(Appendix D Table D1、別紙で確認)、VFes = 2.97 USD/m³

**LIME3日本水:** 0.0061177... US$/m³(統合化係数の消費国・日本選択)

**金額差:** 12,624,579 円(IFVI VFes) vs 57,761 円(LIME3) = 218倍

**乖離の説明度:** 完全に未説明。乖離100%が「既知だが数値化不能な差異」として残差に落ちる

### なぜ負例として重要か

1. **ゼロ意味の保存:** VFnutrition/VFdisease/VFaccess が「計算結果ゼロ」ではなく「公表0」であることを、ゼロ意味フィールドで区別
2. **被覆経路の不一致を止める:** LIME3「人間健康(DALY)」 vs IFVI VFes「生態系サービス毀損(資源可用性)」は、異なる因果経路であり、「倍率で説明すべき差」ではなく「比較不能」として取り扱う(別の価値概念ペアでは気候で実装)
3. **残差構造の実装検証:** 寄与ゼロ・残差=全体差という構造が、数値化可能要因を探索しても見つからない場合の「正しい終わり方」であることを示す

### 直接原因

1. **非ゼロ寄与の手法間成立例が0件**
   - 候補2(LIME3 vs VFes): 地理較正ゼロ寄与、残差が全体差の100%
   - 候補3(LIME3 vs VFnutrition): ゼロ意味 `published_zero`、寄与ゼロ
   - 候補4(代替費用 vs VFaccess): 反実仮想不能で停止

2. **10件以上のコーパスが未構成**
   - 現状: site-042のみ(取水量45,000 m³・デモ既定値)
   - 要件: 同じ比較意味を持つ異なる拠点・フロー・期間の10件以上

### 「実データ実証が成立しない」とは

本レポートにおいて、「状態Bは未達」とは以下を意味する:

- **非ゼロ原因寄与が手法間で存在しない**: 寄与合計 = 0 のペアばかり、または停止。「差が大きい」ことと「原因を説明できる」ことは別。1件でも良いから、説明できたもの(寄与合計 ≠ 0)が必要
- **実データレベルでの検証がない**: デモ既定値(45,000 m³)での診断テストは、「アルゴリズムの正動作確認」であり「実データでの成立確認」ではない
- **但し状態Aは完成**: 技術的には比較・分解・停止が正しく実装され、テストを通過している。実データで試す準備はできている
