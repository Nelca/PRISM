## 1. 必須条件判定マトリクス

### 1.1 判定基準

指示書 §7.1 の4つの必須条件をすべての候補について評価。fail または pending を他項目の加点で相殺しない。

| 条件 | 内容 | 判定方法 |
|---|---|---|
| **条件1** | 同じ実物理入力を2手法以上で評価でき、価値概念と必要な因果経路の比較意味が成立する | 方法論・公開データ・DB案内から「同じフローを両手法で評価するパスがあるか」を確認 |
| **条件2** | 少なくとも1要因について差し替え式を定義でき、採用するFの全部分集合に必要な係数・時間列等を取得できる | 公表式を確認し「各部分集合の再計算が可能か」を判定。公表式がない場合は不能 |
| **条件3** | 現在の実証用途に必要な取得・保存・実行・結果共有が許可されている。商用提供の許諾は別にH-03/H-05で管理する | ライセンス・利用規約から「実証用の非商用使用が許可されているか」を確認 |
| **条件4** | 10件以上の異なる対象へ拡張できる観測データの具体的な取得元がある | 公式公開データ・統計・DB案内で「複数拠点/企業/地域の観測値が取得可能か」を確認 |

## 2. 候補評価

### 2.1 水 — IFVI × LIME3 (既存統合)

| 条件 | 判定 | 根拠 |
|---|---|---|
| **条件1** | **pass** | 同一物理入力：取水量を両手法で評価。価値概念：IFVI・LIME3ともwelfare。因果経路：LIME3は人間健康(単一)、IFVIはVFnutrition/VFdisease/VFes/VFaccess(4分類)。水の人間健康パス(栄養・疫学・水へのアクセス)は両手法で評価・比較可能。参照: `docs/data/aop-mapping-v1.md` §1-2, `docs/data/method-recalculability.md` §3 |
| **条件2** | **pass** | 差し替え式が定義できる要因：地理較正(構想書8.4式)。エンドポイント被覆(LIME3は人間健康のみで内訳公開)・割引率(両手法とも非時間次元)・価値評価技法(IFVI式はapproach選択で内部化済み)は固定。公表式から全部分集合の再計算可能。参照: `docs/data/method-recalculability.md` §3.3, `docs/requirements/m4-divergence-decomposition.md` §7.2.1 |
| **条件3** | **pass** | ライセンス：LIME3はアスエネ社が既に標準版ユーザーライセンス所有(有効期限2027-06-30)。IFVI は2026-08-10の判断で個人利用範囲の条件下で取得済み。実証用の非商用使用を許可。商用提供はH-03/H-05対象。参照: `docs/data/licensing.md`, `docs/data/divergence-decomposition-work-log.md` §2 |
| **条件4** | **pending** | 物理量：拠点別取水量は入手可能(顧客データ・WRI Aqueduct等)。係数：**LIME3は国レベル1本のみ**。IFVI Eq.3-5(拠点別補正)の公表式確認が未完了(方法論PDF手元なし)。「量を変えただけの重複」になるリスク。取得可能なら対象差が生じる条件: H-02-1(IFVI Eq.3-5 PDF再提供) または H-02-4(拠点水源種別データ)。参照: `docs/data/method-recalculability.md` §3.4, `docs/roadmap/divergence-decomposition-completion-directive.md` §7.2.1 |

**判定結果:** 必須4条件中3 pass / 1 pending。**主実証候補ながら条件4 pending のため、成立確認はT-10a後。**

**状態A検証用データ:** LIME3の公表統合化係数(23,696.265 US$/DALY)と地理的視点比(2.56623)、水源種別比(2.5833)は指示書 §7.2.1 で固定済み、状態A検証に優先使用。ただしこれらはLIME3内部の変種であり、「2手法以上」要件を満たさないため状態Bの実証件数へ算入しない。

### 2.2 汚染 — LIME3 × CE Delft または IFVI

| 条件 | 判定 | 根拠 |
|---|---|---|
| **条件1** | **pending** | 同一物理入力：PRTR対象物質×排出媒体での評価は可能(公表)。LIME3・CE Delftとも対応する基本フロー・影響カテゴリを持つか確認中。IFVI側では水専用方法論しか提供されておらず、汚染カテゴリの価値ファクターDBは別途(Global Value Factor Database)。参照必要: H-02-2(CE Delft方法論PDF) |
| **条件2** | **pending** | 差し替え式：第2手法の原本未入手のため、反実仮想の定義可能性が未確認。参照必要: H-02-2(CE Delft) / H-03(IFVI Global DB) |
| **条件3** | **pending** | ライセンス：CE Delft・IFVI Global DBとも原本入手ベース。参照必要: H-02-2, H-03 |
| **条件4** | **pass** | 物理量：PRTR公開データで物質×媒体×事業所が多数。拠点別の排出データ取得可能 |

**判定結果:** 条件1-3 pending、条件4 pass。第2手法の原本未入手が律速。

**採点:** 事業関連性2(開示・税・サプライチェーン重要度から)、根拠充実度0(資料不足)、再現容易さ1(PRTR公開)→計 3/6点

### 2.3 気候 — 社会的費用 × 市場炭素価格

| 条件 | 判定 | 根拠 |
|---|---|---|
| **条件1** | **fail** | 価値概念不一致：社会的費用はwelfare、市場炭素価格(GX-ETS等)はexchange。**本指示書では価値概念の乖離を「倍率で分解すべき差」ではなく「比較不能」として扱う**(構想書8.2、要件定義書§3)。異なる問いを正しく止める負例として採用 |

**判定結果:** 条件1 fail。分解は実施せず、「価値概念不一致」ラベル付けで完成。**負例として活用。**

**採点:** 事業関連性2(GX負債・カーボンニュートラル投資判断)、根拠充実度2(公表方法論・価格軌道)、再現容易さ2(公開データ)→計 6/6点。ただし数値分解不能なため実証候補からは除外。

| 条件 | 判定 | 根拠 |
|---|---|---|

## 7. 実装上の注記

- **状態Aの検証には公表実データを優先使用:** 指示書 §7.2.1 の LIME3 統合化係数・地理較正比・水源種別比は、実装の最初の実データケースに使用。ただしこれらは LIME3 内部変種であり、状態B の実証件数へ算入しない
- **合成データ利用の制限:** 相互作用・ゼロ値・加法分解・停止条件のテストは合成データで可能。ただし成立例(非ゼロ原因寄与)の実演は実データを待つ(T-10a)
- **負例の保存:** 現在の IFVI 日本水ケースの「乖離 100% が残差」は、今後も除外されず、負例として記録・活用される
